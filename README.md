### Engineering practices

- **Lighthouse CI** budgets enforced on every push — failing builds never reach production
- **Playwright** smoke + visual regression suites on critical paths
- **Figma** wireframes (Desktop + Tablet + Mobile + Style Sheet) before any code
- **Design tokens** via CSS custom properties — colors, fluid type, motion presets
- `prefers-reduced-motion` honored in every motion preset
- Mobile-first from 360px up, accessibility-audited before ship
